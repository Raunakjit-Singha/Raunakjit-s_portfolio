01 / Cloud load testing platform / July 2026

LoadForge

A platform that runs load tests against an API and shows how it holds up under high traffic.

  • Java
  • Spring Boot
  • React.js
  • Docker
  • AWS
  • Full stack, from scratch. A React.js frontend and Java / Spring Boot REST APIs that run and analyze API load tests under high traffic.
  • Work that runs in parallel. REST APIs set the test parameters and coordinate the run. AWS SQS feeds Dockerized ECS / Fargate workers, so processing is asynchronous, parallel and microservices-style.
  • Numbers that find the bottleneck. Performance analytics for latency, throughput and failure rates, used to identify and resolve system bottlenecks.
  • Automated delivery. CI/CD and Git workflows handle build, test and deployment.
